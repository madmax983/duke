**ASCII Fast-Path for Char Counting**
**Learning:** `String::chars().count()` forces an O(N) UTF-8 traversal. For ASCII strings, `String::len()` is O(1) and perfectly accurate. Implementing a fast-path via `if s.is_ascii() { s.len() } else { s.chars().count() }` provides a measurable speedup for common text operations (like `equalsignorecase` and `substring`) without breaking Unicode compatibility. Extracting this into a `#[inline]` helper keeps the code readable.
**Action:** When working on string operations in hot paths, consider checking `s.is_ascii()` to short-circuit expensive unicode iterators.
