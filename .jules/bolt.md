**Avoid `write!` inside tight character iteration loops**
**Learning:** Replacing an intermediate `String` and `.replace()` call with per-character `write!(cfg, "{c}")` inside a loop invokes Rust's formatting machinery for every character, introducing massive dynamic dispatch and argument parsing overhead, resulting in a severe performance regression. Furthermore, using literal strings ending with `\n` in `write!` triggers `clippy::write_with_newline`.
**Action:** When eliminating intermediate string allocations, use `String::push(c)` for characters and `String::push_str("\\\"")` for string slices directly on the pre-allocated buffer instead of the `write!` macro.
