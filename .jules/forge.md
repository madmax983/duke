**Extract match on Instruction into methods**
**Learning:** Extracting massive inline match statements that extract properties of an Instruction into methods on Instruction encapsulates the semantic and dries up calling modules.
**Action:** When flattening massive inline match statements extracting properties for an enum, extract the logic into public const fn helper methods directly on the enum to encapsulate semantics and dry up calling modules.
