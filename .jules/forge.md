**Native Handler Argument Checking**
**Learning:** Extracting repetitive type-checking boilerplate in native handlers (e.g., `match args.get(X)`) into shared helper functions significantly reduces visual noise and the "Pyramid of Doom". However, it's critical to ensure the *exact* original error types (e.g., `NullPointerException` vs `TypeMismatch`) are preserved for every edge case to strictly adhere to the "zero behavior change" rule.
**Action:** When extracting generic helpers, carefully analyze the existing error handling paths of all callers. If behavior differs slightly (e.g., some functions returning a default value or throwing a different exception), either parameterize the helper, create specific variants (`get_arg_ref_npe`), or intentionally leave the complex custom logic inline.
