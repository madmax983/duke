Title: 🌟 Nova: JAR Structural Clone Detection

💡 **The Spark:** "Codebases can accumulate technical debt when logic is copy-pasted across different methods or files. Since Duke already decodes JVM bytecode and calculates instruction similarity for basic blocks, we can leverage these to build a tool that detects structural method clones in JAR files."
🚀 **The Feature:** "Implemented a `jar-clones` subcommand in the Duke CLI. It unzips a JAR, parses all classes, extracts method bytecode, and computes pairwise Levenshtein similarity scores (ignoring specific constants/locals) to find structurally identical clones. This relies on the existing `duke-bytecode::similarity` module."
🔮 **The Potential:** "This expands Duke from just a JVM into a static analysis tool. Developers can point `duke jar-clones app.jar` at their application and immediately see where they can refactor duplicate logic. The similarity threshold is configurable (e.g. `0.9` for 90% identical)."
⚠️ **Risk:** "Low. It is entirely additive, isolated in `duke/src/clone_detect.rs`, and runs behind the `nova` feature flag as an optional CLI command."
