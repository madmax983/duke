💡 **The Spark:** "I noticed we calculate dependencies and call graphs for single class files, but lack a holistic view of how an entire JAR application is structured."
🚀 **The Feature:** "Implemented `jar-deps-graph` CLI command that parses all classes within a given JAR and generates a global Mermaid JS dependency graph."
🔮 **The Potential:** "Could be used by architects and auditors to visualize module boundaries, identify tight coupling, and easily map out a third-party application's internal structure."
⚠️ **Risk:** "Low. Strictly additive logic isolated in `duke/src/jar_deps_graph.rs` and gated behind the `nova` feature flag. The core JVM bytecode execution and parsing logic remains untouched."
