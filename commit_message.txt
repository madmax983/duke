⚡ Bolt: Eliminate HashMap and HashSet field clones in native bindings

💡 What: Replaced deep `.clone()` calls on Java object `fields` vectors in various HashMap, HashSet, and LocalDateTime native bindings with scoped immutable borrows.
🎯 Why: Methods like `HashMap.containsKey` or `HashMap.putIfAbsent` previously cloned the entire internal entry array just to avoid borrow checker conflicts (E0502) between reading the elements and subsequently mutating the heap. This resulted in O(N) allocations for O(1) operations.
📊 Impact: Completely eliminates heap allocations for HashMap read operations (get/containsKey) and heavily reduces allocation traffic for inserts/removes. Benchmarks show a ~3.5% performance improvement in `benchHashMap`.
🔬 Measurement: Run `cargo bench` and observe reduced allocation traffic in collection operations.
