🔭 Vantage: Spec for String.equalsIgnoreCase

👤 User Story: As a Java Developer, I want to use `String.equalsIgnoreCase` so I can compare text without writing manual lowercasing logic.
❓ So What? (Business Value): The `slf4j` smoke tests are currently blocked because `String.equalsIgnoreCase` is not implemented natively. Implementing this clears a roadblock in OSS library compatibility, pushing us closer to supporting modern real-world enterprise deployments.
📈 Metric Definition: Success = The slf4j-simple smoke test progresses past `java/lang/String.equalsIgnoreCase(Ljava/lang/String;)Z`.
✅ Acceptance Criteria: Must natively implement `String.equalsIgnoreCase` with correct JVM semantics (returning a boolean).
🚫 Out of Scope: Implementing full locale-aware Unicode case-folding beyond basic ASCII comparisons if that isn't required for SLF4J to pass.
