🔭 Vantage: Spec for Thread.getContextClassLoader() Compatibility

* 👤 **User Story:** "As a Java developer running a real .jar via duke exec, I want java.lang.Thread.getContextClassLoader() to return a valid classloader, so that common libraries such as slf4j-simple can initialize through their standard JDK compatibility path instead of failing before application code runs."
* ✅ **Acceptance Criteria:**
  - Must implement java.lang.Thread.getContextClassLoader().
  - Must return a valid ClassLoader for the main thread.
  - Must allow slf4j-simple to progress past this method call.
  - Integration tests must pass.
* 🚫 **Out of Scope:** Full complex Java ClassLoader hierarchy, Thread.setContextClassLoader(), InheritableThreadLocal classloaders.
