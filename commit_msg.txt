⚡ Bolt: [performance improvement]

💡 What: Replaced unnecessary `.clone()` allocations for `Vec<Slot>` fields on Java objects (like `HashMap`, `Properties`, `ConcurrentHashMap`, `Matcher`) with immutable reference access (`&heap.get(map_ref)?.fields`), eliminating intermediate allocations, and replaced `to_vec()` calls where iterators can be used directly with reference access.
🎯 Why: `heap.get(this_ref)?.fields.clone()` creates a full intermediate O(N) heap allocation and memory copy for the object's instance fields array on every native method invocation that reads them, drastically slowing down hot paths like property lookups, matcher evaluations, and hashmap operations.
📊 Impact: Reduces heap allocations by 1 per native call on these data structures, speeding up iteration and lookups.
🔬 Measurement: Run `cargo bench` or `cargo test`.
