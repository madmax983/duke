🔭 Vantage: Spec for Volatile Market Backtesting

* 👤 **User Story:** "As a Trader, I want to backtest against volatile markets, so that I can validate algorithmic strategies before deploying real capital."
* ✅ **Acceptance Criteria:**
  - Must handle NaN data without panicking.
  - Must output a CSV report.
* 🚫 **Out of Scope:** Real-time execution (Phase 2).
