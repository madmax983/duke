🗺️ Tangle: The codebase contains "Leaky Abstractions" via wildcard exports in foundational crates like `duke-classfile` and `duke-telemetry`. This creates a facade "Blob" pattern where internal module structures aren't strictly bounded, causing a shotgun blast of imported types where only a few are actually needed.

📐 Blueprint: Replace wildcard exports (`pub use module::*`) with explicit type exports (e.g., `pub use module::{StructA, EnumB}`) in `duke-classfile/src/lib.rs` and `duke-telemetry/src/lib.rs`. This enforces tight module boundaries and adheres to the specific public API contract.

🧱 Stability: Reduced coupling, clearer API boundaries, and better maintainability.
🔬 Verification: Builds successfully, all tests pass, and strict separation is enforced without breaking dependencies.
