Title: 🔭 Vantage: Spec for JAR Analysis & Security Tools

👤 **User Story:** As a Security Auditor or Lead Developer, I want to scan and analyze JAR files for potential vulnerabilities and code complexity, so that I can identify risks and prioritize code reviews before deployment.

❓ **So What?** Ensures we don't deploy vulnerable or overly complex code, reducing security incidents and maintenance costs. Success = Scan time < 5 seconds for a 50MB JAR.

✅ **Acceptance Criteria:**
- Must support `jar-scan` command to identify vulnerable APIs.
- Must support `jar-analyze` command to report top 10 most complex methods.
- Must gracefully handle malformed JARs or classfiles.

🚫 **Out of Scope:** Automated patching of vulnerabilities (Phase 2).

🔍 **Gap Analysis:** Current standard tools are either too slow or require commercial licenses.
